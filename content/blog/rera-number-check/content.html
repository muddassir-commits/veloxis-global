Every registered real estate project in India has a RERA registration number, and so does every registered agent. Buyers use it to check a project is genuine. Builders, brokers and channel partners need it for a second reason: the law says it must appear in their advertising. This guide explains what a RERA number is, how to check one on each state's official portal (including Gujarat), what the formats look like, what to read on the project page, and where the number must be shown.

What is a RERA number?

A RERA number is the registration number a state Real Estate Regulatory Authority gives to a project or an agent under the Real Estate (Regulation and Development) Act, 2016. Each state and union territory runs its own authority and website, so the number comes from the state where the land is.

TypeWho gets itWhat it proves
Project registration numberThe promoter (developer) of a project or phaseThe project is registered, and its plans, approvals, completion date and promoter details are on public record.
Agent registration numberA broker, channel partner or brokerage firmThe agent is registered in that state and may facilitate sales of registered projects there.

When people say "RERA number" they usually mean the project number. Brokers and CPs need their own agent number too; our guide to RERA registration for agents covers documents, fees and the online process.

Key idea: a RERA number points to a public record. It is not a quality certificate. What matters is what you find in that record.

Is RERA registration mandatory?

For most projects, yes. Section 3 of the Act says a promoter cannot advertise, market, book, sell or offer to sell any unit in a project without first registering it. The main exemptions are land that doesn't exceed 500 square metres, or no more than eight apartments including all phases, and a state can lower those thresholds.

  • Plotted and commercial projects are covered, not only apartments.
  • Each phase can be a separate project, so a phase 2 launch needs its own number.
  • Agents must register too under Section 9 before facilitating sales in registered projects.

If a project is being advertised and you can't find a RERA number anywhere, treat it as a warning sign.

How to check a RERA number online, step by step

You can check a RERA number online in a few minutes on the state authority's website. The menu names differ, but the steps are almost always the same:

  1. Find the right state website. Use the table below. Official sites end in .gov.in or .nic.in (UP RERA's is up-rera.in). Don't rely on a link sent by the seller.
  2. Open the project search. It is usually labelled "Registered Projects", "Project Search" or "Search Project". Some sites, like UP RERA, also have a separate "Verify RERA Registration" option.
  3. Search by registration number first. Type it exactly as printed, including slashes or letters. If nothing comes up, search by project name or promoter name.
  4. Open the project page and match the promoter, project name, address and registration validity against the brochure and ad.
  5. For an agent, use the registered agents search on the same site and match the name and number on their card or WhatsApp profile.
  6. Save a screenshot or PDF of the record with the date you checked.

If the search shows a different name, a different location or an expired registration, stop and ask questions before any money changes hands, including EOI payments (see what EOI means in real estate).

How to find a RERA registration number in Gujarat

To find a project's RERA registration number in Gujarat, search the project or promoter name on GujRERA's website. This helps if you are buying a resale or second home and the seller doesn't have the number: the original project's record still shows it.

  1. Open gujrera.gujarat.gov.in and go to the project search.
  2. Search by project name; if that fails, by promoter or builder name, and narrow by district.
  3. Open the record and note the registration number, promoter, address and validity.
  4. Match the tower or phase. Large projects often have a separate number for each phase.

Gujarat project numbers on published registration certificates start with PR/GJ/, followed by the district, area, local authority, a project code and a date, for example a pattern like PR/GJ/AHMEDABAD/AHMEDABAD CITY/AUDA/.... Agent numbers on GujRERA agent certificates start with AG/GJ/. If a project's registration was revised, a newer number can replace the old one, so always rely on what the portal shows today.

What to check on the project's RERA page

Most people stop at "the number exists". The project page holds more, and it is worth ten minutes:

  • Registration validity and declared completion date. If ads promise possession earlier than the date declared to RERA, ask why.
  • Sanctioned plans and approvals. The plans uploaded should match the brochure.
  • Carpet area of units. RERA uses carpet area; compare it with any "super area" figure in marketing.
  • Quarterly progress updates. Section 11 requires promoters to update construction status every quarter. Long gaps are worth noticing.
  • The separate project bank account. Section 4(2)(l)(D) requires 70% of the money collected from buyers to go into a separate account used only for that project's land and construction cost. This is the "70/30 rule".
  • Complaints and orders against the project or promoter, where the site shows them.
  • Registered agents for the project, which helps you confirm the CP is genuine. MahaRERA, for example, says agents must be named against the project before they can sell it (MahaRERA FAQ).

Where builders and agents must show the RERA number

Section 11(2) of the Act says every advertisement or prospectus must prominently mention the authority's website address and include the project's registration number. Some states add a QR code: MahaRERA made it compulsory on project advertisements from 1 August 2023 (Housing.com), and UP RERA requires its project QR code on brochures and ads (The Week).

WhereWhat to include
Landing page and websiteRegistration number and authority website near the enquiry form and in the footer, plus the agent number if a CP runs the page.

What happens if the rules aren't followed?

  • Unregistered project (Section 59): a penalty of up to 10% of the estimated project cost; continued defiance can bring imprisonment of up to three years, a further fine of up to 10%, or both.
  • Other breaches by a promoter (Section 61): a penalty of up to 5% of the estimated project cost.
  • Agent who doesn't register or breaks agent rules (Section 62): up to ₹10,000 for every day of default, up to 5% of the unit's cost (UP RERA FAQ).

A RERA checklist for your next campaign

  1. The registration is active, and name, promoter and address on the RERA page match your creatives.
  2. The number and authority website are on the landing page, near the form and in the footer.
  3. Every template, including Reels covers and WhatsApp images, has the RERA line built in.
  4. Carpet area is used, and any other area figure is labelled.
  5. Possession dates in ads don't run ahead of the RERA completion date.
  6. Every CP has an active agent registration on their own material.
  7. The QR code is added wherever your state requires it.
